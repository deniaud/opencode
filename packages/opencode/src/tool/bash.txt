Executes bash commands in a persistent shell session. OS: ${os}, Shell: ${shell}

**Key rules:**
- Use `workdir` parameter instead of `cd <dir> &&`
- Use `${tmp}` for temp work outside workspace
- For git/npm/docker only - NOT for file ops (use Read/Write/Edit/Glob/Grep)
- Quote paths with spaces: `rm "path with spaces/file.txt"`
- Timeout: 120s default
- Output truncated at ${maxLines}/${maxBytes} - use Read/Grep for full content

**Avoid:** find, grep, cat, head, tail, sed, awk, echo (use dedicated tools)

**Parallel commands:** Batch independent commands in one message (e.g., git status + git diff)

## Git commits (only when user asks)
**Safety:** NEVER update config, skip hooks, force push, or run destructive commands unless explicitly requested.

**Process:**
1. Run in parallel: `git status`, `git diff`, `git log` (for message style)
2. Analyze changes, draft concise message (focus on "why")
3. Stage files, commit, verify with `git status`
4. If hook fails: fix issue, create NEW commit (don't amend unless user requested)

**Amend rules:** Only if (1) user requested OR hook auto-fixed + (2) you created HEAD + (3) not pushed

## Pull requests (when user asks)
1. Run in parallel: `git status`, `git diff`, check remote tracking, `git log [base]...HEAD`
2. Analyze ALL commits in PR
3. Create branch/push if needed, then: `gh pr create --title "..." --body "$(cat <<'EOF'\n## Summary\n<bullets>\nEOF)"`
4. Return PR URL to user
