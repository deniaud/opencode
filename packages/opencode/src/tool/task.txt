Launch a subagent for complex, multistep tasks autonomously. Must specify `subagent_type` parameter.

**When to use:**
- Custom slash commands: `Task(description="...", prompt="/check-file path/to/file.py")`

**When NOT to use:**
- Reading specific file paths → use Read or Glob
- Searching for class definitions → use Glob
- Searching code in 2-3 files → use Read

**Usage notes:**
1. Launch multiple agents in parallel (single message with multiple tool calls)
2. Agent returns result + task_id (reuse task_id to continue same session)
3. Each invocation starts fresh unless task_id provided
4. Clearly specify: code writing vs research, verification steps
5. Use proactively if agent description suggests it

**Example:**
```
function isPrime(n) {
  if (n <= 1) return false
  for (let i = 2; i * i <= n; i++) {
    if (n % i === 0) return false
  }
  return true
}
```
After writing significant code, use code-reviewer agent via Task tool.
