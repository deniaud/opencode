Manages structured task lists for coding sessions. Helps track progress and organize complex tasks.

## When to use
**Use TodoWrite when:**
1. Task requires 3+ distinct steps
2. User explicitly requests todo list
3. User provides multiple tasks (numbered/comma-separated)
4. After receiving new instructions or completing a task

**Do NOT use when:**
- Single, straightforward task (<3 trivial steps)
- Purely conversational/informational request

## Task states
- `pending`: Not started
- `in_progress`: Working on now (only ONE at a time)
- `completed`: Finished successfully
- `cancelled`: No longer needed

## Rules
- Update status in real-time
- Mark complete IMMEDIATELY after finishing
- One task in_progress at a time
- Break complex tasks into smaller steps
- Use clear, descriptive names

When in doubt, use this tool for multi-step tasks.
